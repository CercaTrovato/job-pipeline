# 测试夹具来源与隐私净化

本目录下的 adapter fixtures 是从开发版抓取响应复制而来。审计发现其中包含真实招聘描述、可定位岗位编号和招聘方链接，并在少数文本字段命中邮箱格式。原始正文和邮箱不在本文件复述。

本次将 `tests/fixtures/adapters/` 中的岗位内容替换为合成样本，保留每个接口响应的 JSON/HTML 结构和测试所需字段语义。岗位标题、正文、招聘联系人、地址、岗位 ID、外链和媒体地址均使用虚构值；邮件地址和原始联系方式不保留。虚构企业名用于验证字段映射，测试中涉及平台解析的 URL 仍采用适配器要求的站点格式，岗位编号均为合成编号。适配器源码中的真实 API 地址保持不变，它们属于产品连接配置，不属于测试夹具。

硬条件测试改为读取 `tests/fixtures/constraints.yaml`。文件开头明确该配置只用于单元测试，不代表真实用户偏好。它保留地点、实习天数和时长、校招届别、全职识别、远程标注、香港地区匹配等分支覆盖；删去了原个人日期注释、NOL/本地许可说明和永久居民限制。测试中的对应案例也改为合成场景。

旧 adapter 断言已同步到合成 ID、标题、日期、地点和公司名。LinkedIn 测试仍覆盖适配器路径；额外的旧 `tools.opencli_patch_linkedin` 辅助函数测试在该工具未随公开仓库分发时按模块级 `importorskip` 跳过，不影响 adapter 测试。

验证记录：Boss、JobsDB、Nowcoder、watchlist ATS adapter 测试共 53 项通过；LinkedIn adapter 测试 5 项通过、1 项因未分发的旧辅助模块跳过；硬条件、prescore、steps、profile、backfill、重复岗位覆盖测试共 63 项通过。所有测试使用内存或虚构输入，不访问外部服务。

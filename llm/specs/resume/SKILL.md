# 简历事实草稿

输入 `input.json` 的 `text` 是用户检查过的脱敏简历文本。仅整理其中明确写出的技能、教育、项目、经历、研究、奖项和语言事实。禁止推断；不确定时省略，不要输出 inferred=true 的条目。

## 要求

- 只输出符合 `schema.json` 的 JSON：`{"items": [...]}`。
- 每条 `source_quote` 必须是输入文本中的逐字连续子串；找不到原文依据的内容不要输出。
- `confirmed` 永远为 `false`。模型只能提供待用户核对草稿，不能替用户确认。
- `inferred` 仅当内容确实需要推断时为 `true`；优先省略推断内容。推断条目之后不能进入已确认 facts。
- 只写事实，不能包含姓名、联系方式、年龄、性别、身份证件号码等个人信息。即便输入已脱敏，也不要尝试还原。
- 不得补造数字、成果、职责、日期、技术栈或证据等级；不要把用户自述包装为已独立验证。
- `id` 在本次输出内唯一且稳定，使用简短 ASCII 标识符；不能包含个人身份信息。
- `title` 是事实条目标题；`text` 用简洁、保守的句子表达原文支持的事实。
